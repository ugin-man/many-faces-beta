# 使い方

## 自分の動画

「動画を選ぶ」を押して、端末内の動画を選びます。動画はブラウザ内で解析します。解析中は進捗と中止ボタンが表示されます。完了後は再生位置を動かして、合成結果を確認できます。

- **画像保存**：現在の合成画像をPNGで保存します。
- **合成動画保存**：最初から最後まで再生しながら保存します。完了まで画面を開いたままにしてください。形式はブラウザが対応するMP4またはWebM、音声なしです。
- **1コマ戻る・進む**：解析密度に応じて確認位置を動かします。
- **誤画像を報告**：画像IDや時刻を含むJSONを端末に保存します。送信はしません。
- **設定**：解析密度12/20/30fps、鏡表示、顔位置追従、顔写真のみの表示などを選べます。

解析密度と実際の処理速度は別です。長い動画や30fps解析には時間がかかります。顔が検出できない区間は合成済み画面を保持するため、映像が止まって見える場合があります。

## サンプル

右上の小さな「サンプル」から開きます。23.3秒・30fps・699コマの合成済み動画です。再生時の解析はなく、元動画や顔の解析キャッシュは読み込みません。

画像保存、完成済みMP4の保存、30fps単位のコマ送りに対応します。「自分の動画へ」または左上の戻るボタンで通常の動画画面に戻れます。鏡表示は画面と画像保存に適用され、MP4保存は配布ファイルの向きを維持します。

## リアルタイム（デモ）

「リアルタイム（デモ）」に切り替えてカメラを開始します。カメラの許可が必要です。動作や追従速度は端末・ブラウザ・明るさに左右されます。完成済みサンプルの30fpsは、カメラの処理速度を表すものではありません。

## 困ったとき

- 動画が開けない：別のMP4動画で確認してください。対応コーデックはブラウザに依存します。
- 準備に失敗する：通信状態を確認して再読み込みしてください。写真・モデルの初回取得に通信を使います。
- 解析が長い：中止して短い動画や低い解析密度を試してください。
- 顔が逆向き・不自然：コマ送りで確認し、「誤画像を報告」のJSONを添えて知らせてください。

複数人、強い遮蔽、極端な横顔、急な動きでは意図しない結果になる場合があります。公開する動画は全編確認してください。
